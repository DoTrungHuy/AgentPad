# PocketAgent v0.2.5-alpha.1

This pre-release hardens the governed tool-using agent core and adds multi-provider profiles, guided conversation, sequential tool loops, photo picker, and permission-gated local album date search.

## Highlights

- Multi provider / API Key profiles with Keystore-encrypted secrets and connection test before save.
- Guided conversation: clarify vague goals, request missing files/images, block reckless tool use.
- Sequential `AgentLoop` for planned tools: read-only steps can auto-run; external tools still require approval.
- System Photo Picker for images; optional local MediaStore search by year-month after user grants media permission.
- `analyze_image` tool (ACTION approval) for multimodal models; text summary remains separate.
- Security fixes: no file body in working-memory prompts without upload tools, cancel can override racing terminal status, profile key frozen mid-flight, per-action token consume.

## Privacy boundary

- Local album date search is MediaStore-only and does not upload images.
- Image/cloud analysis requires explicit ACTION approval.
- Attachment paths sent to models are redacted metadata only.
- API keys are encrypted per profile and never written to Room or diagnostics.

## Compatibility

- Package id remains `com.agentpad.app` for in-place upgrades from earlier signed builds.
- User-visible app name and release assets use **PocketAgent**.
- Min SDK 28, target SDK 36.

## Build artifact

- APK: `PocketAgent-v0.2.5-alpha.1.apk`
- Produced by GitHub Actions release workflow with the configured release keystore.
